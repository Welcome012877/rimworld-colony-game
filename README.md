# RimWorld: First Colony

A small browser-based colony survival game inspired by RimWorld. It is a lightweight, fan-made prototype built as a static HTML/CSS/JavaScript project.

## Play locally

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Use the action buttons to gather resources and survive the colony's first 30 days.

## Objective

- Gather food, wood, stone, and steel.
- Maintain colonist morale.
- Survive 30 days.
- Build a shelter to increase defense.

## Files

- `index.html` – main page
- `style.css` – visual design and layout
- `script.js` – gameplay logic
